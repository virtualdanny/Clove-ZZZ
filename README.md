# Getting Started

## Usage

1. Download the latest release from the [Releases](../../releases) page.
2. Extract the archive anywhere on your PC.
3. Launch `Launcher.exe`
5. Press **`INSERT`** in-game to open the Clove menu.

---

# Features

**Adventure**

* Noclip

**Battle**

* God Mode
* Dumb Enemies
* Damage Multiplier
* Hit Multiplier

**Visuals**

* Fps Indicator
* Skin Changer (one toggle, all skins)

**Misc**

* Global Speed
* Fps Unlock
* Windows Mouse Cursor
